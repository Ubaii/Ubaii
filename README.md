# 💫 About Me:
I am an Informatics Engineering student with a strong interest in Front-End Development and UI/UX Design. I enjoy creating responsive, modern, and user-friendly website interfaces using HTML, CSS, and JavaScript while continuously improving my front-end development skills. Besides focusing on visuals, I am also interested in understanding how good user experiences can be built through clean and effective interface design.<br><br>During my learning journey, I often work on personal projects such as dashboard websites, landing pages, and application interface designs to improve both my coding and design abilities. I also enjoy exploring design tools like Figma to create wireframes and prototypes before the development process begins.<br><br>I am a fast learner, detail-oriented, and always eager to explore new things in the technology field. Currently, I am continuing to develop my skills in Front-End and UI/UX to create websites that are not only visually appealing but also functional and comfortable for users.
